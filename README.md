Microsoft Exam SC-500 ("Implementing End-to-End Security Controls for Cloud and AI Workloads") earns you the [Microsoft Certified: Cloud and AI Security Engineer Associate](https://learn.microsoft.com/en-us/credentials/certifications/cloud-and-ai-security-engineer-associate/) certification. [1, 2] 
## Overview & Purpose

* Role: Validates the skills required to design, implement, and manage security controls across Azure, hybrid, multi-cloud, and modern AI environments. [3, 4] 
* Transition: Serves as the modern successor and replacement path for the older AZ-500 (Microsoft Azure Security Technologies) exam, which officially retired on August 31, 2026. [3, 5] 
* Focus: Unifies traditional infrastructure and identity defense with cutting-edge AI governance and threat protection. [5] 

## Key Exam Domains

* Identity & Access: Scaling zero trust via Microsoft Entra ID, Privileged Identity Management (PIM), and Conditional Access. [6] 
* Securing AI Solutions: Defending generative AI workloads against prompt injection, jailbreaking, and data poisoning, alongside securing Copilot and AI guardrails using Microsoft Purview. [6, 7] 
* Infrastructure & Compute Defense: Securing storage, databases, networking (Azure Firewall, Virtual Network Manager), and hybrid resources. [6, 7, 8] 
* Security Operations: Managing security posture, threat detection, and incident response using Microsoft Defender and Microsoft Sentinel. [4, 6] 

## How to Prepare

* Review the official [Microsoft SC-500 Study Guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/sc-500) for detailed skill breakdowns and requirements. [7] 
* Take the companion training course [SC-500T00-A](https://learn.microsoft.com/en-us/training/courses/sc-500t00) on Microsoft Learn. [9] 
* Gain hands-on practice managing cloud architecture, KQL querying in Sentinel, and configuring security controls for AI deployments. [5, 6]
